## 1. 定位与信息层级

| 层 | 回答的问题 | 只放什么 |
|---|---|---|
| P1 Pill | 现在怎样？ | 当前 provider 的模式、预算 %、今日、余额（订阅为窗口 %） |
| P2 浮层 | 当前模型现在怎样？ | 预算 / 真实余额 / 本月已花 + 本身份的订阅窗口 + 范围用量表 |
| P3 整页 | 全部家当 + 怎么配？ | API 用量、订阅套餐、范围与明细、设置与数据管理 |

不重复原则：同一事实只在一个层级承担"主展示"；下层补增量，不原样复读。v3.0 起取消双 tab：浮层只讲当前模型，整页讲全部家当。

| 信息 | P1 | P2 浮层 | P3 整页 |
|---|---|---|---|
| 当前 provider 名称 | 否（只有模式徽标） | 是（顶行） | 是（每行一个） |
| 预算 % / 已用总额 | 环 + % | 环 + % + 已用/预算 | 卡片：月度预算输入 · 计划余额 · 真实余额 · 本月已花 |
| 本月已花 / 今日 | 今日 | 本月已花 | 否（API 用量列已用金额） |
| 账户余额 | 是（开关控制） | 是（第三列「真实余额」） | 是（API 用量表「真实余额」） |
| 范围费用 / Tokens | 否 | 摘要带 + 四列用量表 | 四格摘要带 + 趋势柱 + 八列明细表 |
| 按模型明细 | 否 | 四列（模型/Tokens/请求/命中，无费用） | 八列（含费用（API 计价估算）） |
| 订阅窗口 | 是（当前） | 当前 provider 的 1–3 窗 | 全部订阅 provider |

## 2.5 公共组件（P0）

> 三件先于页面落地：环、重置时间、用量表。组件内零 hex、零主题判断，全走宿主语义 token。<br>
> 形态以 [`tools/preview/templates/`](../tools/preview/templates/) 的 HTML 原型为准；本文只定规格与状态，不回写像素。

### 2.5.1 ProgressRing

| 项 | 规格 |
|---|---|
| 用途 | P1 预算与订阅窗口（14/2）、P2 订阅窗口（20/2.5）、P3 卡片 Gauge（40/4，按量与订阅共用同一个组件） |
| 几何 | `viewBox="0 0 ${size} ${size}"`、`r = (size - stroke) / 2`、`strokeDasharray = C*p/100 C`、`rotate(-90 size/2 size/2)`、`strokeLinecap="round"`；`percent = 0` 与 `empty` 都不画弧 |
| 形态 | **描边 donut，中间透明**，不是实心饼 |
| 颜色 | 轨道 `--dsw-alias-border-l3`；**弧与数字同色**：normal 低饱和绿（`--td-state-ok`，回退 `--dsw-alias-state-success-primary`）、warn 黄（`--dsw-alias-state-warn-primary`）、critical 红（`--dsw-alias-state-error-primary`）、empty 不画弧 + 数字 `label-tertiary`；语义固定，色值走 token、不写死 hex |
| 阈值 | 由调用方给：订阅 `≥90` → critical；API 预算 `≥100` → critical；80–100 为 warn，**环与数字同时变黄** |
| 无障碍 | 装饰用法 `aria-hidden`，数值由相邻文本承担；独立使用时 `role="progressbar"` |

- 全量状态（6 态、3 组阈值边界、3 档尺寸、3 种环心）见 [`tools/preview/templates/ring.html`](../tools/preview/templates/ring.html)。

| 项 | 规格 |

- 禁止写死 px 字号、禁止用 `opacity` 模拟弱化、禁止等宽字体族。

### 2.6.1 P1 单一字号与基线判据（v3.19）

- **P1 pill 必须自带 `fontSize` / `lineHeight` / `height`**：它挂在宿主 `composer.dock` 上，不声明就会继承宿主的 16px，前缀与数值会比标签大出一档。
- **同一容器内多字号必然多基线**：基线 = (容器高 − 字形高) / 2 + ascent，`line-height` 无法消除该偏移。因此 P1 收敛为单一 12px，环内数字、周期标签、金额、分隔符全部同字号，实测基线唯一（17.0px，离散 0.0）。
- **不要用 `padding-bottom` 做字形补偿来「对齐」**：该补偿会把文本整体上移 1px，在全行同字号时反而制造 1px 基线差。仅在多字号混排（如 P2）时才可能使用，且须注明适用范围。
- 若未来重新引入 P1 数值层级（例如数值 14px / 标签 12px），**必须重新建立并记录基线判据**，不得沿用本方案的实测值。
- **已知残差（Issue #1）**：盒子居中后，`tabular-nums` 数字的墨迹中心仍比行盒中心低约 0.5px，真机可感知「数字略偏上」。基线一致（0.0px）与光学居中（0.5px 残差）是两件事，前者已达成，后者待处理。

### 2.6.2 P1 段间距（v3.20）

- **API 段**：pill 的 `gap: 6`。段与段之间只有盒子间距，无内联留白。
- **订阅段**：窗口组之间的**单侧视觉留白定值 7px**，由「容器 `gap: 4` + 分隔符 `'・'`（U+30FB，两侧不留空格）」构成。
- 核算口径：`单侧视觉留白 = gap + 分隔符盒宽/2 − 分隔符墨迹宽/2`；12px 下 U+30FB 盒宽 12px、墨迹 6px，故 `4 + 6 − 3 = 7px`。
- 分隔符**不得**再写成 `' ・ '`：两侧半角空格会给每侧多加约 3px 盒宽，使留白从 7px 涨到 12px，视觉上把一条套餐的三个窗口拉散。
- **环下移 0.75px**：文字基线一致后，环墨迹中心（11.84）仍比文字墨迹中心（12.58）低 0.74px，视觉上数字显得沉下去。把环整体下移 0.75px 后环心 12.75，残差 0.17px。移环而非移文字，因为 SVG 平移不依赖字体度量。该值绑定「环径 14 / 字号 12」的组合，改变其一需重新核算。

## 2.7 间距

统一 4px 栅格，只允许以下六档；P2 / P3 模板与 `client.js` 已迁移，P1 仅保留 4px 内联间距。

| token | 值 | 用途 |
|---|---|---|
| `--space-1` | 4px | 图标与文字、环与百分比、标签与输入框 |
| `--space-2` | 8px | 卡片行、表格列距、表头下边距 |
| `--space-3` | 12px | 卡片网格、区块内部 gap、明细上边距 |
| `--space-4` | 16px | 卡片 / 底框 padding、页头左右组间距 |
| `--space-5` | 24px | 区块间距、页面上下留白 |
| `--space-6` | 32px | 页面上下 padding（P3） |

- 禁止 6 / 10 / 14 / 18 等中间值；1px 只用于描边与分隔线。
- 卡片与底框 padding 16；区块间距 24；卡片间 12；行内 8 或 4。
- 趋势柱与摘要带**不新增间距档**：分隔线 1px、段间距 12（`--space-3`）、标签与数字 4（`--space-1`）、多币种金额 8（`--space-2`）；柱区间距 2 与柱宽上限 36 属**图形几何**，登记在 `SPEC.trend`，不并入间距阶梯。

### 4.2 尺寸与定位

- 宽 **固定 380**，`max-width: calc(100vw - 16px)`；面板 padding 16，内容宽 346（380 − 32 − 2 边框）；不再随内容变化，避免切 provider / 金额时跳宽；模型名 `max-width: 150px` + 省略号。

- 取消「用量 / 设置」双 tab；取消预算进度条；取消刷新间隔 / 余额开关。

### 4.3 主区三组（左 / 中 / 右 三栏对齐）

- 单行三栏：`display: grid; grid-template-columns: minmax(0,1fr) minmax(0,1.5fr) minmax(0,1fr); column-gap: 12px`：环+百分比 / 已用·预算 / 真实余额。
- **对齐职责分离**（Issue #2 · 已实施）：左栏 `align-items:flex-start` 贴内容左缘；中栏 `align-items:center` 栏内居中；右栏 `align-items:flex-end` + `text-align:right` 贴内容右缘，与标题行 `[ API 用量 ]` 共用同一条右边线。
- 中间栏给 1.5fr 是因为 `¥91.90 / ¥100.00` 是三栏中最长内容；左右两栏内容短，1fr 仍可贴边。
- 不得把右栏改成左对齐：会破坏「余额贴右缘」的原始设计。
- 环 / 已用·预算位置不动；不再渲染「本月已花」，也不留无内容的第四组。
- 标签 11px `label-secondary`，值 12px / 600。
- `title`：余额=「账户真实余额，不受预算影响」。
- **失败态（Issue #4 · 已实施）**：`/summary` 或 `/usage` **任一接口失败**时，标题栏的刷新图标**替换为带文字的「重试」按钮**：**实红描边**（`--dsw-alias-state-error-primary`）+ 14% 红底、红色文字、`font-weight:600`，高 22、圆角 6、11px。
- 判定口径 `failed = error || usageError`：不让用户分辨「这次坏的是哪一半」，点一次即两个接口一起刷新（`refreshAll`）。
- **全屏只有一个重试入口**（标题栏），表体内不再插入任何错误条或重试按钮。实红框而非淡色描边，是为了与右侧蓝色关闭按钮在形态和语义上清晰区分。
- **表体清空**：`/usage` 失败即 `setUsage(null)`，表格降级为空态「范围内暂无消耗」，不展示上次数据——避免用户把陈旧数字当成当前值。
- 长金额优先让模型名截断，不换行、不缩字号。

### 4.4 订阅行

- 固定三槽位 `repeat(3, 1fr)`：第 1 窗左对齐、第 2 窗居中、第 3 窗右对齐；两窗占前两个槽位，单窗占左槽位。

- **每个 provider 一张卡**：flex 布局，卡宽上限 260（3 家一行 3 张、末行居中），gap 12；卡内 padding 16、圆角 8、1px `border-l3`。

- 卡顶：供应商名 + `[ API 用量 ]`；卡内**竖排居中**：`QuotaGauge(40)`（环心「已用」）→ 环下百分比 → `月度预算` 标签 → 输入框。
- 卡内三行：计划余额（预算 − 已用，可为负）/ 真实余额 / 本月已花；不再单列「已用 / 预算」。
- 额度型 provider（如 Ollama）在「真实余额」后按字段追加两行：套餐已用（`已用 / 总额`）、购买余额；两者无数据时不渲染，普通 provider 卡形不变。真实余额是「套餐剩余 + 购买余额」的合计。

- 改预算后环、状态、计划余额即时重算：80–100% 环与数字同黄，≥100% 同红；金额不用状态色，负值红。
- 只列 `billingMode === 'api'`；计费模式只读；`billingModes = hide` 的 provider 不出现。
- 原型：[`cards-api.html`](../tools/preview/templates/cards-api.html)。

### 5.4 订阅套餐（按供应商）

### 5.5 范围与明细

- 时间范围胶囊、摘要带、使用趋势、模型明细共用一个底框（1px / 圆角 10 / padding 16），框内 12px 分区 + 1px 分隔线（v3.13 新增趋势一段）。
- 顶部行：范围胶囊与「共 N 个模型 · 更新于」同行、**整行左对齐**（16px 间距）。
- **摘要带四格**（v3.13，已定稿；v3.14 顺序调整）：整宽、`repeat(4, minmax(0,1fr))` + 1px 竖分隔；每格 `padding: 12px 8px`、gap 4、纵向居中。
  - **顺序（v3.14）**：真实 Tokens → 总费用 → 缓存命中率 → 总请求数，**与右侧指标胶囊同序**；两处顺序同源于 `TREND_METRICS`，禁止各写一份。命中率放第 3 是因它是唯一的非累加型（百分比）指标，夹在两个计数指标中间会被误读为可加总项。窄屏 2×2 时为上排「Tokens / 费用」、下排「命中率 / 请求数」。
  - 层级：标签 12px / 常规 → 数字 **22px / 600** / 行高 26px → 副行 11px / `label-tertiary`。
  - 总费用：多币种同行、8px 间距，单币种时居中；副行「{n} 个币种」。
  - 真实 Tokens：副行「输入 x · 缓存 y · 输出 z」，三点以 8px 间距连接。
  - 总请求数：范围内全部模型的请求合计（**含订阅行**），副行「范围内全部模型」。
  - 缓存命中率：`cacheRead ÷ (input + cacheRead + cacheWrite)`，分母 0 显示 `—`；副行「创建 x · 命中 y」。
  - **四格兼作趋势指标选择器**：格子是 `button[role=radio]`，外层 `role=radiogroup`；选中格底色 accent 10%、标签转 accent 色；悬停为文本色 4%；默认选中「真实 Tokens」。
- **使用趋势柱**（v3.13，已定稿）：位于摘要带与明细表之间；`border-top` 1px + `padding-top` 12px 与摘要带分隔，与明细表之间也靠 1px 分隔线。
  - 标题行：左「使用趋势 · {指标}」13px / 600 + 11px「按天」；右端为指标胶囊。
  - 指标胶囊：容器高 26、`padding: 2px`、圆角 8、底色 `127,127,127 10%`；每项高 22、内边距 8、圆角 6、11px；选中项白底深字（`rgba(255,255,255,.92)` / `#1c1c1e`）。与四格**双向同步**：任一入口改动，图表、四格选中态、胶囊选中态同时更新。
  - 柱区高度固定 **132px**（不随数据塌陷）；底部 **18px** 留给日期刻度。
  - 柱：flex 等分（`flex: 1 1 0`）、间距 2px、圆角 `3px 3px 0 0`、宽度上限 **36px**（单点时不拉满整宽）；颜色取 accent；零值与无数据柱不画（透明占位，保住柱距）。
  - 网格：只有上、中、下三条 1px 横线（下线上移 18px，与刻度区分隔），无纵线、无外框。
  - Y 轴：标注「最大 / 中间」两档，11px / `label-tertiary`；中间档取 `(下限 + 上限) / 2`。刻度格式按指标走：Tokens「万 / 亿」、请求整数、费用带币种符号、命中率百分比。
    - **轴在绘图区之外（v3.18）**：柱区改为两列网格——左列独占轴（宽度按最长刻度估算后定宽），右列才是绘图区（网格线、柱、悬停层、日期刻度都只在右列内活动）。轴不再绝对定位在绘图区内部，避免与柱体视觉重叠。与 CC Switch 的 `<YAxis>` 同构。
    - **上限取值（v3.18）**：命中率轴上限定为 100%（数据常见 99.6%，按数据取值会让顶档既不好看也不对称）；其余指标仍取数据最大值。
    - **底部档（v3.17）**：坐标下限不为 0 时额外补出下限档，与底部网格线对齐；下限为 0 时省略。
    - **命中率下限忽略离群 0%（v3.18）**：单个 0% 日（当次请求全未命中）不再把下限拽回 0，避免中档出现 49.8% 这类无意义刻度；无有效数据时仍回落到 0。
    - 变更注记：Y 轴渲染在 `v3.15`（悬停虚线改造 `c41b9eb`）中被误删且未同步本规格，`v3.17` 恢复，`v3.18` 移出绘图区并修正上限 / 下限口径。
  - X 轴刻度：日期 `MM-DD`，按点数抽稀为约 6 个（`ceil(n / 6)` 步长），末点必显；刻度行高 18、居中。
  - 命中率轴**不从 0 起**：下限 = 本批最低值 − `max((1 − 最低值) / 2, 0.02)`，向下取整到 5% 档；结果 < 50% 时回落为 0。
  - 多币种时「费用」指标禁用：柱区中央显示「多币种下成本柱不可用，请切换其他指标」，**不静默取首个币种**。
  - 无数据：保留网格与 132px 高度，中央一行「该范围内暂无消耗」。
  - 悬停（v3.15）：鼠标进入柱区即显示**垂直虚线指示线**（1px dashed，accent 色，`opacity .9`，压在柱体之上）+ 柱顶圆点 + 自绘浮层 `YYYY-MM-DD · 精确值`；不使用原生 `title`（其显示延迟约 1s，且无法绘制指示线）。悬停单位是**等分槽**，零值日同样可悬停。移出柱区即清空；切换指标 / 时间范围时同步清空，避免旧柱位残留。不加十字准线，不引入图表库。
- **明细表分区标题（v3.18）**：明细表上方新增独立区块标题行「模型明细」13px / 600 + 右侧 11px 说明「范围按当前时间范围统计」，与「使用趋势」标题行同构；标题行上方 16px 外边距 + 1px 分隔线，与柱状图形成清晰视觉断点。
- 明细表：模型 / Tokens / 输入 / 缓存 / 输出 / 请求 / 命中 / 费用，8 列；模型列上限 240，数值列 `minmax(56px, 1fr)`、字号 13，Tokens 沿用「单位 / `[` 交界」基线；窄屏内部横向滚动（`min-width: 720px`）。
- 只列范围内有消耗的模型；模型名后追加 ` · 供应商`，列距 8。
- 除模型列外，表头与数值全部右对齐到列右缘（含 Tokens）。
- **费用列四态**（唯一实现处）：`kind !== 'api'` → 单行 `≈¥x`（缺价时 `未定价`，字段缺失时 `—`）；`priced === 'empty'`（零消耗）→ `—`；`priced === false` → `未定价`，单元格 `title` 给出可读原因（无匹配价目 / 候选模型不唯一 / 模型名无效）；其余一律 `≈¥x`。
- **估算标记统一（v3.20.1）**：`≈` 表示**金额为本地估算**（不是「价格来源近似」）。API 行与订阅行同一形态，一律 `≈¥x`；订阅行不再使用「预估」前缀。缺价 `未定价`、零消耗 `—` 均不加 `≈`。该值不参与排序、不进总计、不进任何费用聚合（费用口径仍只认 `kind === 'api'`）。

#### 5.7.1 UpdateButton（版本行右端的更新控件）

抽成独立组件的更新控件，原型见 `tools/preview/drafts/update-button.html`（`npm run preview drafts/update-button`）。

**尺寸**：按钮高 **22px**、字号 **11px**、圆角 **6px**；图标 13px；行高 26px 不变——抽出组件不改变「版本」行现有排版。

**状态矩阵（7 态）**

| 状态 | 按钮 | 按钮右侧 | 说明 |
|---|---|---|---|
| `idle` | 下载图标，默认边框 | — | 无更新 / 尚未检测 |
| `checking` | loader 转圈，禁用 | — | 防止重复点击 |
| `available` | 下载图标 + 「更新」文案；accent 描边 42% + 浅底 16% + accent 文字 | `vX.Y.Z`（accent / 11px / 500） | **有更新必须整体强调，不能只靠小圆点**；点击直接安装 |
| `installing` | loader 转圈 + 「更新中」，disabled，保持 accent 外观 | — | 持续数秒到数十秒，无进度百分比 |
| `done` | 对勾图标 | 状态文字「已更新到 X.Y.Z，重启 DSH 后生效」 | 1.6s 后回 `idle` |
| `error`（手动） | 刷新图标 + 「重试」；over 色描边 + over 文字 | 「检查失败」（over / 11px，`role=alert`） | **点击直接重新安装**；「复制命令」降为次要入口 |
| `error`（自动） | **保持 idle 外观**，不变红 | 「更新检查失败」（over / 11px，`role=alert`） | 5s 后自动消失 |

**设计约束**

- **失败分级**：手动检查失败必须强提示（按钮转红 + 可重试）；自动检查失败是后台行为，只给低强度文字，5s 自动消失，**不得让按钮变红**——否则用户没做任何操作页面却忽然变红。
- **移除小圆点**：`dot` 不再用于表达「有更新」或「错误」。状态一律由按钮外观 + 右侧文字承载，避免「看到一个点但不知道是什么」。
- 版本号在有更新时常显于按钮右侧，不依赖 `title` hover。
- 自动检测**不再静默**：失败时右侧显示「更新检查失败」，并写 `[TD:update]` 日志带 `errorKind` / `httpStatus`。
- **无二次确认**（v3.17）：点「更新」直接开始安装，没有确认条，也没有撤销窗口。按钮在 `idle` 是「检查更新」、`available` 才是「更新」，文案与颜色双重区分。
- **无障碍播报**：提示节点带 `role="status"` + `aria-live="polite"`；失败态改 `role="alert"` + `aria-live="assertive"`。

**检测频率**

| 时机 | 行为 |
|---|---|
| 插件 `apply` | 30s 后触发一次自动检测（等 UI 稳定） |
| 启动检测 | **无条件执行**——不看缓存、不看上次检测时间 |
| 运行中 | **每 4h 一次**自动检测 |
| 手动点击 | 不受周期限制 |

- 启动检测**无条件执行**：不看缓存、不看上次检测时间，每次启动都检查。
- 启动检测与手动点击都带 `?refresh=1`，绕过宿主 5min 缓存，确保拿到的是当下最新版本而非几分钟前的旧结果。
- 上次检测时间戳仅用于**运行中周期检测**与「恢复可见时是否到期」的判定，不参与启动决策。

## 6. 交互与可访问性

- Pill：`role=button`、`tabIndex=0`、Enter/Space、`aria-expanded`、完整 aria-label。
- Panel：`role=dialog`；范围选择器用 `role=tablist`（roving tabindex）；P2 无 tab。
- Segmented：每项 `role=tab`、`aria-selected`，roving tabindex；←/→/Home/End 移动，Enter/Space 选择。
- **摘要带四格**（v3.13）：容器 `role=radiogroup` + `aria-label="趋势指标"`；每格 `button[role=radio]` + `aria-pressed`；Tab 可达，Enter/Space 选择。
- **趋势指标胶囊**：复用 `Segmented`（`kind='radiogroup'`），每项 `role=radio`、`aria-checked`，roving tabindex + ←/→ 移动；与四格共享同一 `metric` 状态，两处选中态始终一致。
- **趋势柱**：整体 `aria-hidden` 的纯图形 + 每根柱原生 `title`；不加 tabIndex，键盘用户通过上方四格 / 胶囊获取同一数值，不引入第二套导航。
- Toggle：`role=switch`、`aria-checked`；Space/Enter 切换；关闭后不改变焦点位置。
- 关闭入口有三个：右上角 `×`、点击面板外部、`Esc`；P3 为整页，用侧栏切回会话即离开；关闭后尽力归还焦点。
- `Esc` 由 `document` 级 keydown 监听，面板打开时按下即关闭，不要求焦点在面板内。
