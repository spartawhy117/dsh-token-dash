## 三、组件契约

> 环只画几何，数字与文案由组合层承担；不给 `ProgressRing` 加数字槽位。

| 组件 | 职责 | 不负责 |
|---|---|---|
| `ProgressRing` | 弧长、描边、尺寸：`{ percent, state, size, stroke }` | 任何文字 |
| `PercentValue` | `42.5%` / `—`、按状态上色 | 位置与间距 |
| `InlineRing` | 环 + 右侧数字（P1/P2） | 拼词条 |
| `QuotaGauge` | 环心标签 + 环下数字 + 三行辅助（P3） | 解析数值 |

| 状态 | 弧 | 百分比 |
|---|---|---|
| normal | 低饱和绿 | 同绿 |
| warn（80–100） | 黄 | 同黄 |
| critical（订阅 ≥90 / API ≥100） | 红 | 同红 |
| empty | 不画弧 | `—` |

- 公共函数 `stateOf` / `percentText` 三页共用。
- `percent = 0` 不画弧，避免 round linecap 留点。
